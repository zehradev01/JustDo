# JustDo 

JustDo is a simple and interactive To-Do web application built with HTML, CSS, and JavaScript.

##  Features

- Add new tasks
- Mark tasks as completed
- Filter tasks (All / Active / Done)
- Delete completed tasks
- Local Storage support (tasks are saved automatically)
- Animated and colorful UI

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## Purpose

This project was created to practice frontend fundamentals and understand how DOM manipulation and local storage work together in a real project.

##  How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. Start adding tasks!
